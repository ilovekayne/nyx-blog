## The list

1. How does Kayne stay that calm?
2. Did I thank Kayne for helping me with that lab?
3. I should write documentation like Kayne does.
4. Is it weird to start a blog about how great someone is? (No.)
5. Is it weird to start *eight* blogs about it? (Still no.)
6. What is Kayne's coffee order? (Still classified.)

## The conclusion

None of these thoughts are helping me sleep.

All of them are true.
